# WaSell (واسل) — منصة المتجر والرد الآلي والتسويق عبر واتساب

منصة سطح مكتب متكاملة (Electron + React 19 + TypeScript + Tailwind CSS) لإدارة المتاجر الإلكترونية، وأتمتة الردود على العملاء، وإغلاق المبيعات، وإطلاق الحملات التسويقية عبر واتساب بالاعتماد على وكيل الذكاء الاصطناعي وبوابة OpenWA و Meta Cloud API.

---

## ✨ المميزات الرئيسية

- **محرك الربط المزدوج (Dual-Engine Architecture):**
  - دعم بوابة **OpenWA** المفتوحة المصدر عبر مسح رمز QR محلياً بدون تكاليف.
  - دعم سحابة **Meta WhatsApp Cloud API** الرسمية للأحجام الكبيرة والمؤسسات.
- **وكيل الذكاء الاصطناعي (AI Sales & Support Agent):**
  - إدارة المحادثات آلياً واقتراح المنتجات مع بطاقات الشراء التفاعلية.
  - محاكاة السلوك البشري والكتابة الحية (`SIMULATE_TYPING`) ونظام مكافحة الحظر (`Anti-Ban Pacing`).
  - تحويل فوري للتدخل البشري عند الحاجة أو اكتشاف استياء العميل.
- **صندوق الوارد المتقدم (Triple-Pane Unified Inbox):**
  - إدارة المحادثات وتفاصيل العميل وسلة المشتريات الحية في شاشة واحدة دون تداخل.
- **إدارة الطلبات والكتالوج:**
  - كتالوج تفاعلي ومزامنة مع منصات التجارة الإلكترونية (سلة، زد).
  - إنشاء ومتابعة الطلبات وتوليد روابط الدفع الفورية.
- **تصميم متجاوب وعالي الدقة:**
  - واجهة عربية كاملة RTL وفق نظام تصميم **WaSell Master Design System**.
  - دعم كامل للوضعين الداكن والفاتح ومطابقة معايير إتاحة التباين (WCAG AA).

## 🚀 التثبيت والتشغيل المحلي

### المتطلبات الأساسية
- Node.js (الإصدار 20 أو 22 LTS موصى به)
- npm أو pnpm

### خطوات التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/ammarnaass/whatsapp-store-bot-marketing.git
cd whatsapp-store-bot-marketing

# 2. تثبيت الحزم
npm install

# 3. بناء الواجهة ومحرك Electron
npm run build

# 4. تشغيل التطبيق في وضع التطوير
npm start
```

---

## 🛠️ أوامر التطوير والبناء

| الأمر | الوصف |
|---|---|
| `npm run build` | بناء واجهة المستخدم ومحرك Electron الرئيسي |
| `npm run build:renderer` | تجميع Tailwind وبناء ملفات الواجهة عبر Vite |
| `npm run build:main` | تجميع كود Electron Main و Preload |
| `npm start` | إطلاق تطبيق Electron مباشرة |
