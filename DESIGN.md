## Brand & Style

This design system powers a conversational commerce workspace and autonomous sales agent tailored for fast-scaling regional and global brands. Built with an Arabic-first mindset, the visual language prioritizes clarity, systematic structure, and high trust. The personality is disciplined, trustworthy, and futuristic without being speculative—blending the utility of enterprise infrastructure with the speed and intimacy of instant messaging.

### Design Style: Modern Corporate & Conversational Utilitarian
The aesthetic unites crisp modern enterprise SaaS with purposeful dual-mode cues. Everyday operations rely on calm WhatsApp-rooted emeralds and deep forest greens, while autonomous intelligence features are explicitly partitioned using an electric violet accent. This visual bifurcation eliminates operator uncertainty by ensuring that machine-driven interventions, automated checkouts, and AI recommendations are unmistakably clear at a glance.

### Visual Principles
- **RTL-First Equilibrium:** Every spatial rhythm, icon direction, data trend indicator, and conversational thread flows naturally right-to-left, with seamless mirror handling for Latin characters.
- **Cognitive Clarity Over Noise:** White, clean surfaces contain dense analytical data without sensory fatigue; low-contrast hairline dividers replace heavy drop shadows.
- **Explicit Agency (Human vs. Machine):** WhatsApp greens anchor transactional and human actions, while luminous purple accents mark AI actions, prompt states, and autonomous recommendations.

## Colors

The palette establishes an immediate bridge between conversational familiarity and cutting-edge autonomous intelligence. 

### Core Palette
- **Primary (`#128C7E`):** Core action color. Applied to affirmative primary buttons, live connection status indicators, active tabs, and customer touchpoints.
- **Secondary / Deep Anchor (`#075E54`):** Grounding tone. Applied to persistent navigation frames, key transactional headers, focused input borders, and high-impact metric counters.
- **Tertiary / AI Kinetic Violet (`#7C3AED`):** Dedicated exclusively to AI copilots, machine-suggested responses, auto-generated catalog tags, and autonomous toggle controls.
- **Surface Tint / Mint Badge (`#E7F6F2`):** Soft contextual wash for positive order indicators, connected session badges, and muted table active-row backgrounds.

### Surfaces & Neutrals
- **App Canvas:** `#F6F7F9` (Light) / `#0F172A` (Dark)
- **Container / Card Background:** `#FFFFFF` (Light) / `#1E293B` (Dark)
- **Primary Text:** `#1F2937` (Light) / `#F8FAFC` (Dark)
- **Muted Text / Secondary:** `#64748B` (Light) / `#94A3B8` (Dark)
- **Structural Outlines / Dividers:** `#E5E7EB` (Light) / `#334155` (Dark)

### Functional Feedback
- **Success:** `#10B981` (Completed orders, synced webhooks)
- **Warning:** `#F59E0B` (Approaching rate limits, pending cart abandonment)
- **Danger:** `#EF4444` (Emergency AI killswitch, failed payments, disconnections)
- **Info:** `#0284C7` (Sync logs, platform update bulletins)

## Typography

Typography relies on IBM Plex Sans (configured with IBM Plex Sans Arabic for native scripts) across all hierarchical tiers. This typeface delivers crisp glyph distinctions, neutral geometric terminals, and balanced open counters that optimize readability for dense Arabic tabular metrics, numbers, and bi-directional chat strings.

### Rules of Engagement
- **Numeric Clarity:** Numbers within financial summaries, metrics, and timestamps should use localized tabular numeral styling (`font-variant-numeric: tabular-nums`) to prevent jitter across real-time data refreshes.
- **Vertical Flow:** Because Arabic letterforms possess distinct ascenders and descenders relative to Latin, line heights are adjusted slightly wider (`1.5` to `1.6` relative ratio) to eliminate vertical ligature clipping.
- **Letter Spacing:** Absolute zero tracking on all Arabic textual levels; tracking expansions are applied exclusively to Latin labels or code snippets.

## Layout & Spacing

The layout model is anchored on an 8pt metric grid, employing a fluid multi-column master shell with a fixed right-hand navigation rail (mirrored to the left under LTR mode).

### Canvas Architecture
- **Right-Hand Primary Navigation Rail:** 260px expanded width; collapses to a 72px icon-only rail on compact screens.
- **Top Utility & Command Bar:** 64px fixed vertical height across viewport sizes. Houses workspace selection, dynamic session connectivity status, global search, and the Emergency AI Killswitch.
- **Operational Grid:** 12-column dynamic fluid grid on viewports $\ge 1200\text{px}$, collapsing to 6 columns on tablet devices ($768\text{px}-1199\text{px}$), and a single stacked stream below $768\text{px}$.

### Layout Breakpoints
- **Desktop ($> 1200px$):** Fixed rail + contextual secondary drilldown drawer (380px) + flexible data viewport.
- **Tablet ($768px - 1199px$):** Collapsed icon rail, responsive metrics cards wrapping to 2x2.
- **Mobile ($< 768px$):** Hidden rail under off-canvas overlay, stacked single-column metric tiles, horizontal filter scrolls.

## Elevation & Depth

Visual hierarchy uses crisp boundary delineation rather than heavy atmospheric shadows, ensuring enterprise operational software feels lightweight and fast.

### Elevation Tiers
- **Flat Ground (Level 0):** Background canvas (`#F6F7F9` / `#0F172A`).
- **Base Cards & Surfaces (Level 1):** Solid white card fill with a 1px structural stroke (`#E5E7EB` / `#334155`) paired with a micro ambient drop: `0px 1px 2px rgba(15, 23, 42, 0.04)`.
- **Interactive State & Hover (Level 2):** Subtle upward card shift using `0px 4px 12px rgba(15, 23, 42, 0.06)`, stroke shifts slightly darker.
- **Drawers & Floating Context Windows (Level 3):** Right-anchored chat drawers and flyout filter menus: `0px 10px 25px -5px rgba(15, 23, 42, 0.10)`, with background backdrop filter blur (`backdrop-filter: blur(8px)`).
- **Emergency / Modal Overlays (Level 4):** Killswitch alerts and critical confirmation modals: `0px 20px 35px -10px rgba(15, 23, 42, 0.20)`.

### AI Surface Depth
AI copilot blocks, suggestions, and auto-composed responses feature a soft ambient glow: `0px 0px 0px 1px rgba(124, 58, 237, 0.15), 0px 2px 8px rgba(124, 58, 237, 0.06)`.

## Shapes

The interface embraces a balanced modern curvature that softens data density without wasting screen real estate.

### Shape Scale
- **Base Radius (`0.5rem` / 8px):** Applied to form inputs, search fields, table pagination controls, dropdown items, and inline utility buttons.
- **Component Large (`1rem` / 16px):** Metric scorecards, chart view containers, conversation transcript bubbles, and side drawers.
- **Interactive Micro Elements (`9999px` / Full Pill):** Session state pills (متصل / غير متصل), numeric unread count badges, operational filter tags, and quick-filter chips.

## Components

### Buttons
- **Primary Action (Transactional):** Background `#128C7E`, text `#FFFFFF`, radius 8px. Hover shifts to `#075E54`. Active state compresses slightly (`scale(0.98)`).
- **AI Agent Action:** Background `#7C3AED`, text `#FFFFFF`, radius 8px, left-aligned sparkles icon (right-aligned in RTL). Hover shifts to `#6D28D9`.
- **Emergency AI Killswitch Button:** Background `#FEE2E2`, border 1px solid `#FCA5A5`, text `#DC2626`, pill or 8px radius. On hover: solid `#EF4444` background with `#FFFFFF` text. Triggers a prominent safety confirmation modal.
- **Secondary / Ghost:** Transparent background with 1px border `#E5E7EB`, text `#1F2937`.

### Session Status Pill
- **Connected (متصل):** Pill wrapper with `#E7F6F2` background, `#075E54` text, featuring an animated 6px pulsating `#10B981` dot on the leading edge.
- **Disconnected (غير متصل):** `#FEF2F2` background, `#991B1B` text, static gray or red indicator dot.

### KPI Metric Cards
- Surface `#FFFFFF` with 1px `#E5E7EB` border, 16px radius, padding 20px.
- Displays label top right (RTL), numeric value in bold 28px IBM Plex Sans, accompanied by percentage variance tag (green for gain, rose for decline) and micro sparkline trend indicator.

### Input Fields & Search Bars
- Background `#FFFFFF`, 1px border `#D1D5DB`, radius 8px, padding `10px 14px`.
- Focus state activates a 1px border of `#128C7E` with a subtle focus ring (`0 0 0 3px rgba(18, 140, 126, 0.15)`).
- Search input carries an RTL-aligned search icon with dedicated placeholder typography (`ابحث عن طلب، عميل، أو محادثة...`).

### Conversation & Feed Bubbles
- **Customer Bubble:** Right-aligned (RTL incoming), background `#F3F4F6`, text `#1F2937`.
- **Human Agent Reply:** Left-aligned (RTL outgoing), background `#E7F6F2`, border 1px solid `#A7F3D0`.
- **AI Autonomous Reply:** Left-aligned (RTL outgoing), background `#F5F3FF`, border 1px solid `#DDD6FE`, with small badge: `بواسطة الذكاء الاصطناعي`.

### Data Tables with Status Badges
- Zebra-free layout with hairline border dividers (`#E5E7EB`). 
- Row hover triggers faint mint highlight (`rgba(231, 246, 242, 0.4)`).
- Badges use pill geometry with 4px vertical padding and 10px horizontal padding, utilizing semitransparent semantic fills (e.g., `#D1FAE5` with `#065F46` text for Paid/Delivered).
